# Telecom Customer Churn Analysis & Prediction

An end-to-end Data Analytics and Machine Learning project focused on predicting customer churn in the telecom industry. This project combines SQL for data cleaning and preprocessing, Power BI for interactive dashboard visualization, and Machine Learning techniques for churn prediction and business insights.

---

## Project Overview

Customer churn is one of the major challenges faced by telecom companies. The objective of this project is to analyze customer behavior, identify churn patterns, and build predictive models that help businesses improve customer retention strategies.

This project demonstrates the complete data workflow:
- Data Cleaning & Transformation using SQL
- Exploratory Data Analysis
- Interactive Dashboard Creation in Power BI
- Machine Learning Model Development
- Predictive Analysis for Customer Churn

## Project Workflow

### 1. Data Cleaning & Preprocessing
- Cleaned raw telecom customer data using SQL queries
- Handled missing values and inconsistent records
- Performed data transformation and feature preparation

### 2. Data Visualization
- Developed an interactive Power BI dashboard
- Analyzed:
  - Customer demographics
  - Churn distribution
  - Monthly charges
  - Contract types
  - Payment methods
  - Internet services

### 3. Machine Learning Model
- Built churn prediction models using classification algorithms
- Split dataset into training and testing data
- Evaluated model performance using:
  - Accuracy Score
  - Confusion Matrix
  - Classification Report

### 4. Business Insights
- Identified major factors contributing to customer churn
- Generated actionable insights for improving customer retention
